# 俄罗斯方块

使用原生 HTML、CSS、JavaScript 和 Canvas。无框架、无外部依赖，可离线运行。

## 在浏览器中运行

双击本目录中的 `index.html`，或将文件拖到 Chrome、Edge、Firefox 浏览器中，点击“开始游戏”。无需安装 Node.js 或启动服务器。

## 操作

| 按键 | 操作 |
| --- | --- |
| ← / → | 左右移动（按住可连续移动） |
| ↑ | 顺时针旋转 |
| ↓ | 加速下落（按住可连续下落） |
| 空格 | 立即落底并锁定 |
| P | 暂停 / 继续 |

页面提供开始、暂停、重新开始和触屏按钮。切换窗口或标签页会自动暂停。
半透明轮廓表示落点，侧栏显示下一块。

## 规则

- 棋盘为 10 列、20 行，使用七种方块，七袋随机发块。
- 横向填满一行即可消除；同时消除 1 / 2 / 3 / 4 行分别获得 100 / 300 / 500 / 800 分，乘以消行时的等级。
- 加速下落每格加 1 分；立即落底每格加 2 分。
- 每消除 10 行升一级，下落速度随等级增加。
- 新方块生成位置被占据时游戏结束。
- 使用简单横向踢墙旋转；方块到达底部或下方障碍后锁定。

## 文件与检查

- `index.html`：页面。
- `style.css`：样式与窄屏布局。
- `core.js`：独立游戏规则。
- `game.js`：绘制、按键和动画循环。
- `tests/core.test.cjs`：规则检查。安装 Node.js 后在本目录执行 `node --test tests/core.test.cjs`。
