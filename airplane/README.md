# 小飞机 · 云端出击

用浏览器打开 `index.html`，点击“开始游戏”即可游玩。原生 HTML、CSS、JavaScript 和 Canvas，无需安装依赖，可离线运行。

- 方向键或 WASD 移动，飞机自动发射子弹。
- 手机或平板按住战场拖动飞机。
- P、空格或暂停按钮暂停 / 继续；离开窗口会自动暂停。
- 击落敌机获得 10 分，每 100 分升级。敌机逐渐加速、出现更频繁。
- 初始 3 条生命，撞到敌机会扣除一条，随后获得 1.8 秒无敌保护。敌机飞出战场不会扣分。
- 生命耗尽后显示成绩，可以重新开始。最高分保存在当前浏览器；存储不可用时仅在页面打开期间保留。

规则检查：`node --test airplane/tests/core.test.cjs`（从仓库根目录执行）。
