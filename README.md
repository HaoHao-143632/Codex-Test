# Codex-Test

无需安装依赖的浏览器小游戏，用浏览器打开对应的 HTML 文件即可游玩。

- [小飞机 · 云端出击](airplane/index.html)：自动射击、键盘和触控移动、等级提升及最高分记录。见 [操作说明](airplane/README.md)。
- [俄罗斯方块](tetris/index.html)：经典消行玩法。见 [操作说明](tetris/README.md)。

## 微信小程序

- [英语天天打卡](english-checkin/README.md)：面向人教版 PEP 六年级上册新版的单词、阅读和朗读打卡。用微信开发者工具导入 `english-checkin` 目录，按操作说明在手机上预览。
